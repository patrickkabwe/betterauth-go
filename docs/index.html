Setup in seconds

Create an instance, mount the handler. That's the whole server.

main.go 
package main

import (
	"log"
	"net/http"

	"github.com/patrickkabwe/betterauth-go/auth"
	"github.com/patrickkabwe/betterauth-go/store/memory"
)

func main() {
	a, err := auth.New(auth.Config{
		Secret:         "your-secret-at-least-32-chars-long",
		BaseURL:        "http://localhost:8080",
		TrustedOrigins: []string{"http://localhost:3000"},
		Store:          memory.New(), // or store/sql for Postgres/SQLite/MySQL
	})
	if err != nil {
		log.Fatal(err)
	}

	mux := http.NewServeMux()
	// Mount every Better Auth endpoint under /api/auth
	mux.Handle("/api/auth/", http.StripPrefix("/api/auth", a.Handler()))

	log.Fatal(http.ListenAndServe(":8080", mux))
}

Works with net/http, chi, Gin, Echo, Fiber — anything that speaks http.Handler.

Connect any Better Auth client

The wire format matches the official server, so existing clients just work.

auth-client.ts 
import { createAuthClient } from "better-auth/react";

export const authClient = createAuthClient({
  baseURL: "http://localhost:8080", // your Go server
});

await authClient.signUp.email({ name: "Jane", email: "jane@example.com", password: "securepass" });
const { data: session } = await authClient.getSession();

A CLI that matches @better-auth/cli

Generate a feature-scoped schema, migrate, scaffold, and more.

terminal 
# install the CLI
go install github.com/patrickkabwe/betterauth-go/cmd/betterauth-go@latest

betterauth-go secret                                # generate BETTER_AUTH_SECRET
betterauth-go generate --plugins organization       # schema for enabled features only
betterauth-go migrate  --database "file:auth.db"     # apply it
betterauth-go init     --name "My App"              # scaffold a project

Schema is feature-scoped: only the tables your enabled plugins need are generated.
